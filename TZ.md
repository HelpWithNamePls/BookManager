# Функциональные требования

Система должна выполнять следующие функции:


| Функция | Что делает |
| --- | --- |
| Добавление книги | Пользователь вводит id, автора, год издания и общее кол-во экземпляров. Система проверяет уникальность id и добавляет запись в массив books.|
| Просмотр всех книг | Система перебирает массив books и выводит таблицу: id, название, автор, год, доступно/всего |
| Просмотр всех пользователей | Выводит таблицу пользователей. Номер,имя,роль |
| Поиск по автору | Вводится фамилия и система ищет соответствия и выводит все совпадения  |
| Поиск по названию | Работает аналогично поиску по автору |
| Выбор книги по id | Вводят id система находит книгу и выводит ее информацию|
| Выдача книги | Пользователь вводит id книги и табельный номер читателя. Происходит проверка что они оба существуют и книга доступна. Если все условия совпали книга удаляется, а общее кол-во доступных книг уменьшается|
| Возврат книги | id книги, табельный номер читателя. Система ищет запись в журнале issued - удаляет ее и увеличивает кол-во доступных книг |
| Сохранение и загрузка | при старте программа читает файл с данными, а при выходе записывает текущее состояние в этот файл |

# Пользовательские сценарии

## Сценарий 1 Добавление новой книги

1. Пользователь запускает программу.
2. Она загружает данные из файла(если он есть).
3. Пользователь выбирает пункт 1.
4. Система запрашивает данные.
5. Происходит проверка уникальности id. Если он не уникален - выводит ошибку и возвращает в меню
6. Книга добавляется в массив и выводит подтверждение
7. Пользователь выбирает пункт 0 для выходаю
8. Система сохраняет данные в файл(а если его нет создает и сохраняет) и завершает работу


## Сценарий 2 Поиск и выдача книги

1. Пользователь выбирает пункт 4. Поиск по автору и вводит "Булгаков"
2. Выводится все книги с указанием доступных экземпляров
3. Пользователь запоминает id нужной книги
4. Выбирает пункт 8, вводит id и номер читателя
5. Система проверяет есть ли книга и читатель, доступна ли книга
6. Книга доступна. Уменьшает значение на 1, добавляет метку
7. При выходе файл сохранения изменяется

## Сценарий 3 Возврат книги

1. Читатель возвращает книгу с ID 101.
2. Пользователь выбирает пункт 9, вводит ID 101 и табельный номер 1001.
3. Система ищет запись в issued по паре (bookId, userTab).
4. Если запись найдена — удаляет её, увеличивает available на 1, выводит подтверждение.
5. Если записи нет — выводит ошибку «Запись о выдаче не найдена».
6. Пользователь выбирает пункт 2, чтобы убедиться, что счётчик available вернулся к исходному значению.

# Технические ограничения

Платформа: Windows

Кодировка: UTF-8 для исходного файла и консоли. На Windows требуется SetConsoleOutputCP(65001) и сохранение файла в UTF-8 с BOM.

Объём данных: до 1000 книг и 500 пользователей без потери производительности (ограничение vector не жёсткое, но для учебного проекта этого достаточно).

Хранение: только локальный текстовый файл, без базы данных и сетевого взаимодействия.

Многопользовательский режим: отсутствует. Программа рассчитана на одного оператора за одним компьютером.

Зависимости: только стандартная библиотека C++; сторонние библиотеки не используются.

Сборка: один исполняемый файл, без установки.





1. Запуск, сохранение и загрузка
При первом запуске программа открывается без ошибок (даже если файла с данными еще не существует).
Если файл с данными существует, при запуске программа автоматически загружает книги и пользователей, и они отображаются в списках.
При выборе пункта «Выход» (или закрытии окна) программа сохраняет все текущие изменения (добавленные книги, выданные экземпляры) в файл.
Если запустить программу заново после сохранения, все ранее введенные данные остаются на месте.

2. Добавление книги (Пункт меню "Добавить книгу")
При вводе уникального ID, названия, автора, жанра, года и количества — книга успешно добавляется в систему, появляется сообщение об успехе.
«Проверка на дубликат:» Если ввести ID, который уже существует в системе, программа выдает ошибку («Такой ID уже есть») и не добавляет книгу.
«Валидация (проверка данных):» Если оставить поля пустыми или ввести буквы в поле «Год выпуска» / «Количество книг», программа выдает ошибку и не дает добавить запись (или не дает нажать кнопку).

3. Поиск и просмотр (Главное меню и Архив)
«Поиск по названию:» При вводе названия книги (или его части) в строку поиска и нажатии кнопки «Найти» — в результатах появляется нужная книга.
«Поиск по автору:» При вводе фамилии автора — выводятся все книги этого автора.
«Поиск по ID:» При вводе ID — выводится конкретная книга.
«Отрицательный тест:» Если ввести слово, которого нет в базе (например, «абракадабра»), программа выводит сообщение «Ничего не найдено» или показывает пустой список (программа не должна вылетать).
«Архив:» При открытии окна «Архив» отображается таблица со всеми книгами (Название, Автор, Жанр, Год, Количество, В наличии).
«О книге:» При клике на книгу из списка открывается окно «О книге» с полной информацией и кнопками (Взять, Изменить, Удалить, Назад).

4. Выдача книги (Взять книгу)
В окне «Взять книгу» отображается название выбранной книги.
При вводе Имени, Телефона, Почты и Даты возврата и нажатии кнопки — книга успешно выдается.
«Уменьшение количества:» После выдачи общее количество доступных экземпляров этой книги уменьшается на 1 (или книга помечается как выданная).
«Ошибка:» Нельзя выдать книгу, если доступных экземпляров 0 (программа должна выдать сообщение «Книги нет в наличии»).

5. Возврат книги
В окне «Вернуть книгу» пользователь вводит Имя, Телефон и Почту.
Если такой пользователь брал книгу, возврат проходит успешно, запись удаляется из журнала выдач.
«Увеличение количества:» После возврата количество доступных экземпляров этой книги увеличивается на 1.
«Ошибка:» Если пользователь с таким именем и телефоном не брал книгу, программа выдает ошибку («Запись о выдаче не найдена»).

6. Интерфейс и Админ-панель
Все окна (Меню, Добавить, Взять, Вернуть, Архив) открываются и закрываются без зависаний.
Кнопка «Вернуться в меню» корректно закрывает текущее окно и возвращает в главное меню.
«Пароль админа:» При нажатии на кнопку «Пароль админа» открывается маленькое окошко.
«Проверка пароля:» Если ввести неправильный пароль, доступ не предоставляется (ошибка). Если правильный — открывается доступ к редактированию/удалению книг.
 «Смена пароля:» В окне смены пароля при вводе нового пароля и нажатии кнопки — пароль действительно меняется (старый пароль перестает работать).

7. Общая стабильность
 Программа не вылетает (Crash) при выполнении любых действий.
 Если в поля ввода (телефон, имя) ввести спецсимволы или очень длинный текст, программа обрабатывает это корректно и не ломается.
