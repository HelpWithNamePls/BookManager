# Функциональные требования

Система должна выполнять следующие функции:


| Функция | Что делает |
| --- | --- |
| Добавление книги | Пользователь вводит id, автора, год издания и общее кол-во экземпляров. Система проверяет уникальность id и добавляет запись в массив books.|
| Просмотр всех книг | Система перебирает массив books и выводит таблицу: id, название, автор, год, доступно/всего |
| Просмотр всех пользователей | Выводит таблицу пользователей. Номер,имя,роль |
| Поиск по автору | Вводится фамилия и система ищет соответствия и выводит все совпадения  |
| Поиск по названию | Работает аналогично поиску по автору |
| Выбор книги по id | Вводят id система находит книгу и выводит ее информацию|
| Выдача книги | Пользователь вводит id книги и табельный номер читателя. Происходит проверка что они оба существуют и книга доступна. Если все условия совпали книга удаляется, а общее кол-во доступных книг уменьшается|
| Возврат книги | id книги, табельный номер читателя. Система ищет запись в журнале issued - удаляет ее и увеличивает кол-во доступных книг |
| Сохранение и загрузка | при старте программа читает файл с данными, а при выходе записывает текущее состояние в этот файл |
