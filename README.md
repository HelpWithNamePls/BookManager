# Общая информация

Это учебный проект, находящийся в разработке.

BookManager

Консольная система учёта книг на C++ для небольших библиотек.

BookManager помогает автоматизировать учёт фонда: добавлять книги, искать их по автору, выдавать и возвращать экземпляры, а также отслеживать их доступность.

## Отказ от ответственности

Данный код может содержать ошибки, авторы не несут никакой ответственности за любые последствия использования этого кода.

## Возможности

-  Добавление книг в каталог
-  Поиск по автору и названию
-  Выдача и возврат книг
-  Учёт доступных экземпляров
-  Управление пользователями (читатели и библиотекари)

## Требования

- Компилятор с поддержкой **C++17** (GCC, Clang или MSVC)
- Терминал (командная строка)
